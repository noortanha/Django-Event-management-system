# Event Management System

A full-stack Event Management application built with Django for backend and HTML/CSS/Tailwind for frontend. Users can browse events, create events, and register for events.

## Tech Stack
- Backend: Django
- Frontend: HTML, CSS, Tailwind CSS
- Database: SQLite / PostgreSQL
- Tools: Git, GitHub

## Features
- User authentication and role-based permissions (Admin, User)
- CRUD operations for events
- Event registration and list management
- Responsive frontend using Tailwind CSS
